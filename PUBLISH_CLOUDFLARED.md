# Временная ссылка через Cloudflare Tunnel

Этот способ подходит, если нужно быстро показать приложение, которое работает на вашем компьютере. Ссылка временная: сайт доступен, пока запущены Streamlit и `cloudflared`.

## Подготовка

Установите `cloudflared`, если его ещё нет. На macOS с Homebrew:

```zsh
brew install cloudflared
```

На Windows установите программу с [официальной страницы Cloudflare](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/).

Проверьте, что чат запускается на компьютере и отвечает AI. Для работы также нужен интернет.

## Запуск

1. Откройте первое окно Terminal, перейдите в папку проекта, включите окружение и запустите Streamlit:

   ```zsh
   cd ~/GitHub/streamlit-bot
   source venv/bin/activate
   streamlit run main.py --server.port 8501
   ```

   Не закрывайте это окно: в нём работает приложение.

2. Откройте второе окно Terminal и запустите туннель:

   ```zsh
   cloudflared tunnel --url http://localhost:8501
   ```

3. Найдите в сообщениях `cloudflared` ссылку, которая заканчивается на `.trycloudflare.com`, и откройте её в браузере.

Любой, у кого есть ссылка, сможет открыть чат и отправлять вопросы, которые используют ваш API-ключ и могут расходовать ваш лимит. Не публикуйте ссылку для личного или важного приложения. Для Quick Tunnel не нужно настраивать входящие порты или открывать firewall.

Чтобы закрыть доступ, нажмите `Ctrl+C` в обоих окнах Terminal. При следующем запуске ссылка изменится. Этот способ предназначен для демонстрации, а не для постоянной публикации сайта.
