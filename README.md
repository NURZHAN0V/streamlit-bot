# План проекта: сайт с чат-ботом

Цель: создать веб-страницу с чатом, подключить к нему AI-модель и опубликовать приложение в интернете.

## 1. Подготовить проект и создать чат

### 1.1. Проверить Python

Откройте Terminal на macOS и проверьте версию Python:

```zsh
python3 --version
```

Если команда не найдена, попробуйте:

```zsh
python --version
```

Дальше используйте ту команду (`python3` или `python`), которая показала версию. Если не работает ни одна, установите Python и снова откройте Terminal.

На Windows проверьте Python командой:

```powershell
py --version
```

Если она сработала, создавайте окружение командой `py -m venv venv`.

### 1.2. Создать виртуальное окружение

Перейдите в папку проекта. Например:

```zsh
cd ~/GitHub/streamlit-bot
python3 -m venv venv
source venv/bin/activate
```

Если у вас сработала команда `python --version`, вместо `python3 -m venv venv` выполните `python -m venv venv`.

После активации в начале строки терминала появится `(venv)`. Важно: файл `activate` не запускают напрямую, его подключают командой `source`.

Для Windows команды отличаются:

```powershell
py -m venv venv
venv\Scripts\Activate.ps1
```

### 1.3. Установить библиотеки

Выберите один из двух способов. Не нужно выполнять оба.

**Способ 1: установить сразу.** Пока виртуальное окружение активно, выполните:

```zsh
python -m pip install streamlit requests
```

**Способ 2: установить по списку.** Создайте рядом с `main.py` файл `requirements.txt` и запишите в него:

```text
streamlit
requests
```

Затем выполните:

```zsh
python -m pip install -r requirements.txt
```

Для публикации хостингу понадобится `requirements.txt`. Если сначала выбрали способ 1, создайте этот файл перед публикацией, чтобы хостинг знал, какие библиотеки установить.

### 1.4. Написать код чата по частям

Откройте `main.py`. На каждом этапе копируйте весь блок кода целиком в этот файл, заменяя его прежнее содержимое. Так не придётся угадывать, куда вставлять отдельные строки.

**Шаг 1. Создайте простой чат.** Скопируйте этот блок полностью в `main.py`:

```python
# Подключаем инструмент, который показывает страницу и чат.
import streamlit as st

# Пишем заголовок страницы.
st.title("Чат-бот")

# Создаём список переписки, если его ещё нет.
if "messages" not in st.session_state:
	 st.session_state.messages = []

# Показываем сообщения, которые уже есть в переписке.
for message in st.session_state.messages:
	 with st.chat_message(message["role"]):
		  st.markdown(message["content"])

# Добавляем поле, куда посетитель напишет сообщение.
prompt = st.chat_input("Напишите сообщение...")

# Показываем и запоминаем новое сообщение.
if prompt:
	 st.session_state.messages.append({"role": "user", "content": prompt})
	 with st.chat_message("user"):
		  st.markdown(prompt)
```

Этот вариант показывает страницу, принимает текст и оставляет его в переписке. Ответа AI пока нет.

Запустите приложение:

```zsh
streamlit run main.py
```

Откройте адрес из терминала, обычно `http://localhost:8501`, и проверьте, что сообщение появляется на странице. Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

## 2. Подключить AI-ассистента

### 2.1. Получить API-ключ

Создайте ключ в кабинете AI-провайдера. Ключ нужен приложению для отправки запросов; его нельзя публиковать в открытом репозитории или показывать на скриншотах.

Для локальной разработки создайте файл `.streamlit/secrets.toml`:

```toml
# Вставьте вместо текста в кавычках свой ключ.
TIMEWEB_API_KEY = "вставьте_свой_ключ"
```

Создайте папку `.streamlit` рядом с `main.py`, внутри неё создайте файл `secrets.toml` и вставьте туда этот текст. Замените слова в кавычках на свой ключ.

Если настоящий ключ уже попадал в исходный код или переписку, отзовите его в кабинете провайдера и создайте новый.

### 2.2. Добавить ответ AI

Теперь соберите полный код программы из двух частей. Очистите `main.py`, вставьте первый блок в начало файла, а второй сразу после него. Не удаляйте первый блок, когда будете вставлять второй.

```python
# Подключаем отправку сообщений и создание страницы.
import os
import requests
import streamlit as st

# Указываем адрес AI, ключ доступа и выбранную модель.
API_URL = "https://api.timeweb.ai/v1/chat/completions"
API_KEY = os.getenv("TIMEWEB_API_KEY") or st.secrets["TIMEWEB_API_KEY"]
MODEL = "dashscope/qwen3.6-flash"

# Добавляем заголовок страницы.
st.title("Чат-бот")

# Создаём список переписки при первом открытии страницы.
if "messages" not in st.session_state:
	st.session_state.messages = []

# Показываем сохранённые сообщения.
for message in st.session_state.messages:
	with st.chat_message(message["role"]):
		st.markdown(message["content"])

# Добавляем поле для нового сообщения.
prompt = st.chat_input("Напишите сообщение...")
```

Первая часть показывает сохранённую переписку и поле для нового сообщения.

```python
# Выполняем эти действия, когда посетитель отправил сообщение.
if prompt:
	st.session_state.messages.append({"role": "user", "content": prompt})
	with st.chat_message("user"):
		st.markdown(prompt)

	# Просим AI ответить и показываем его в чате.
	with st.chat_message("assistant"):
		try:
			response = requests.post(
				API_URL,
				headers={
					"Authorization": f"Bearer {API_KEY}",
					"Content-Type": "application/json",
				},
				json={
					"model": MODEL,
					"messages": st.session_state.messages,
					"temperature": 0.7,
				},
				timeout=60,
			)
			response.raise_for_status()
			data = response.json()
			answer = data["choices"][0]["message"]["content"]
		except (requests.RequestException, KeyError, IndexError, ValueError):
			answer = "Не удалось получить ответ. Проверьте подключение, ключ и название модели."

		st.markdown(answer)
		st.session_state.messages.append(
			{"role": "assistant", "content": answer}
		)
```

Вторая часть передаёт вопрос AI, показывает его ответ и сохраняет ответ в чате. Вместе обе части образуют полный код приложения.

Запустите приложение командой `streamlit run main.py` и задайте короткий вопрос. Если ответа нет, проверьте ключ в `secrets.toml` и имя модели.

### 2.3. Запустить приложение на компьютере в локальной сети

Для обычной разработки достаточно команды `streamlit run main.py`. Команда ниже заставляет Streamlit принимать подключения на всех сетевых интерфейсах компьютера:

```zsh
streamlit run main.py --server.address 0.0.0.0
```

Это может дать доступ к приложению другим устройствам в той же сети, но само по себе не публикует сайт в интернете. Не запускайте такую команду в публичной сети без понимания настроек доступа и безопасности.

В результате получится сайт с чатом, который отвечает на вопросы с помощью AI и доступен по интернет-ссылке.

Навыки из проекта пригодятся, чтобы создавать полезные инструменты для учёбы, работы и повседневных задач: например, помощника, который отвечает на частые вопросы или помогает разобраться в информации.

Этот чат станет основой для будущих AI-агентов. Их можно будет научить не только отвечать, но и выполнять полезные действия. Такой подход применяют и в реальных проектах.
